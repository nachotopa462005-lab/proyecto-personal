# Testing y mejoras

Durante esta fase estuve probando el funcionamiento general del proyecto, tanto el frontend como el backend y la conexión con la API. Hice pruebas manuales de las funcionalidades principales para comprobar que todo responde como debería y que la comunicación entre las distintas partes es correcta.

También revisé el diseño responsive, asegurándome de que la interfaz se adapta bien a distintos tamaños de pantalla. En general, la experiencia es bastante consistente tanto en escritorio como en dispositivos más pequeños.

Por otro lado, estuve pendiente de posibles errores en la consola durante las pruebas. De momento no me encontré con bugs importantes que requieran corrección, aunque eso no significa que no puedan aparecer más adelante.

Aun así, el proyecto no está cerrado. Todavía quedan mejoras por hacer, tanto a nivel de interfaz como de organización del código y posibles optimizaciones. Seguiré revisando y puliendo detalles en las siguientes fases.
