# Proyecto personal — Finanzas

App para gestionar finanzas personales: entender en qué se gasta, visualizar estadísticas y ayudarte a planificar el mes.

## Tablero

- **Link**: `https://trello.com/b/a78tyz64/gestor-de-gastos`

## Estructura del repo

- **`frontend/`**: Vite + React + TypeScript + Tailwind + React Router
- **`docs/`**: documentación del proyecto y del proceso
- **`server/`**: estructura base para backend (fase 3) si se decide incluirlo en este repo

## Cómo correr el frontend

```bash
cd frontend
npm install
npm run dev
```
